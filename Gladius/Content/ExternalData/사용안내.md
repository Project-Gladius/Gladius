# 로컬 방송 운영 파일

개발 프로젝트와 배포본 모두 `Gladius/Content/ExternalData`가 운영 폴더입니다.
이 폴더는 압축 패키지 밖의 일반 파일로 빌드에 포함됩니다. 로컬 배포본을 옮길 때 폴더 전체를 함께 복사하세요.
프로그램을 종료한 상태에서 파일을 수정하고 다시 실행하세요. 기록 자동 저장을 위해 프로그램 폴더에는 쓰기 권한이 필요합니다.

## 방송 설정: BroadcastSettings.json

| 항목 | 입력 내용 |
|---|---|
| youtube.videoId | 유튜브 방송 영상 ID. 주소 전체가 아니라 watch?v= 뒤의 ID |
| youtube.apiKeys | YouTube Data API 키 목록. 문자열 배열이며 순서대로 교체 사용 |
| youtube.streamKey | OBS 등의 방송 송출 키 보관란. 게임의 채팅 조회에서는 사용하지 않음 |
| operators[].userId | 운영자의 실제 UC 채널 ID 또는 @핸들. 표시 이름은 인증 정보로 사용하지 않음 |
| operators[].channelId | @핸들에 대응하는 UC 채널 ID. 비워 두면 기존 확인 결과를 유지하거나 YouTube API로 확인 |
| operators[].adminName | 공지 등에 표시할 운영자 별칭. 빈 값은 GM |

현재 확인된 API 키, 방송 영상 ID, 운영자 목록은 기존 설정에서 옮겼습니다.
송출 키는 기존 로컬 환경에서 확인된 값이 있을 때만 채웠습니다. 비어 있으면 이 파일의 youtube.streamKey에 직접 입력하세요.
API 키와 송출 키는 서로 다른 값입니다. API 키는 youtube.apiKeys에 입력하세요.
API 키 목록 또는 송출 키가 비어 있거나 공백이면 프로그램이 BroadcastSettings.json을 30초마다 다시 읽습니다.
API 키를 채우면 자동 반영하고 필요한 경우 채팅 연결을 다시 시도합니다. 두 항목이 모두 채워지면 주기적인 재확인을 멈춥니다.
파일 저장 중 JSON 형식이 잠시 불완전하면 마지막 정상 값을 유지하고 다음 주기에 다시 확인합니다. 기존 키의 할당량 소진 기록은 초기화하지 않습니다.
영상 ID·운영자 목록 등 나머지 설정을 바꿀 때는 프로그램을 다시 실행하세요.

operators는 다음 실행 때 적용할 운영자 전체 목록입니다. 새 항목을 추가하면 권한을 부여하고, 항목을 제거하면 기존 운영자 권한을 해제합니다.
운영자 목록을 잘못 입력하거나 중복 ID를 넣으면 기존 권한을 유지하고 오류를 남깁니다. @핸들만 입력한 계정은 실제 채널 ID가 확인되기 전에는 운영자로 인증되지 않습니다.
실행 중 방송 파일을 자동으로 덮어쓰지 않습니다. 관리자 명령으로 바뀌는 차단·이벤트 기록은 UserData.json에 저장됩니다.

## 나머지 파일

| 파일 | 용도 |
|---|---|
| UserData.json | 실제 사용자 권한·차단·이벤트 적용 이력. 프로그램에서 자동 저장 |
| PlayerData.json | 실제 참가자의 성장 수치와 전투 기록. 프로그램에서 자동 저장 |
| abilities.json | 공통 전투 규칙과 캐릭터 능력치 |
| bosses.json | 보스 행동·상태·패턴 |
| enhancements.json | 강화·축복 수치 |
| BattleSchedule.csv | 전투 시작 시간표. StartTime 헤더와 HH:MM 형식 |
| ConnectionSettings.json | AI 배치 요청 주소와 클라이언트 토큰. UseExternalConnectionSettings=true일 때 적용 |
| TempleAI.env | AI 서버의 Gemini 키·모델·공유 토큰. 서버 환경변수가 파일보다 우선 |
| goddess_profile.md | AI 여신의 설정과 응답 규칙. AI 서버를 다시 시작하면 반영 |
| BattleData.md | 전투 JSON 필드 설명 |

실제 키와 기존 기록은 로컬 전용 배포본에 포함하도록 설정했습니다. 기존 Saved/UserData.json, Saved/PlayerData.json, Config/YouTubeApiKeys.txt 대신 이 폴더가 기준입니다.
패치할 때는 기존 운영 폴더의 키·방송 설정·사용자 기록을 백업하고 유지하세요. 새 초기 파일로 기록을 덮어쓰지 마세요.
실행 중 생성되는 원문 채팅 로그는 기존 Saved/ChatLogs에 저장합니다.

## AI 서버 실행

AI 서버는 게임과 별도 프로세스입니다. 배포본의 `Gladius/Server/TempleAI_Phase1`에 서버 소스, requirements.txt, StartServer.cmd가 포함됩니다.
Python 3.12 이상이 설치된 컴퓨터에서 requirements.txt를 설치한 뒤 StartServer.cmd를 실행하세요.
TempleAI.env의 GEMINI_API_KEY에 기존 실제 값이 없다면 실제 키를 입력해야 합니다. 클라이언트 토큰은 ConnectionSettings.json의 TempleAIClientToken과 같아야 합니다.
원격 서버를 그대로 이용할 경우 서버 환경변수와 접속 주소를 유지하면 됩니다.
서버를 다른 위치에 따로 배치할 때는 GLADIUS_EXTERNAL_DATA_DIR 환경변수로 운영 폴더 경로를 지정할 수 있습니다.

## 빌드 포함 항목

ExternalData 전체와 Content/FMOD/Desktop 음원 뱅크를 일반 파일로 포함합니다.
두 메인 맵과 게임 UI·폰트는 Cook 목록에 포함됩니다. 캐시·테스트 결과·채팅 로그는 배포 데이터에 넣지 않습니다.
