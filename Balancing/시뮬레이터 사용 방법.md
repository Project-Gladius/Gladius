# 시뮬레이터 사용 방법

**[Gladius 시뮬레이터.html](Gladius%20시뮬레이터.html)을 더블클릭해 Chrome 또는 Edge로 열면 됩니다.** 서버, 인터넷 연결, Node.js 설치가 필요하지 않습니다. 다른 컴퓨터에서 사용할 때도 HTML 파일 하나만 복사하세요.

1. 시작 체력·피버와 두 공격의 능력치를 입력합니다.
2. 확률 입력 또는 위치 반영 모드를 선택합니다.
3. 보스 행동을 최대 10턴까지 추가·삭제하고 각 턴을 편집합니다.
4. 자동 계산된 라인을 비교합니다. 순위는 생존 성공 시 평균 대미지 기준입니다.
5. 행동 셀을 수정하면 그 턴까지 고정한 대안이 아래에 추가됩니다.
6. 옵션에서 최초·추가 라인 수와 세부 전투 규칙을 조정합니다.

**입력을 보관하려면 닫기 전에 JSON → 전체 설정 내보내기를 사용하세요.** HTML 자체에 편집 내용이 덮어써지지는 않습니다. 다음 실행 시 JSON 화면에서 저장한 파일을 가져오면 됩니다.

기존 보스 패턴 JSON도 가져올 수 있습니다. 남은 턴 안에 들어가는 패턴만 추첨하여 행동표로 펼칩니다.

## 위치 모드의 전체 라인 통계

- **전체 라인 생존 비율**: 매 턴 공격 1·공격 2·방어·좌/중/우 회피의 6가지 선택을 조합한 전체 `6^N`개 라인 중 마지막 턴까지 체력이 남는 라인의 비율입니다. 현재 위치로 회피하는 선택도 포함합니다. 각 라인을 동일하게 센 비율이며, 최적 행동을 선택한 플레이어의 생존 확률과는 구분됩니다.
- **같은 대미지 라인 생략**: 최적 행동 라인 표의 체크박스를 선택하면 대미지별 대표 하나를 표시합니다. 소수 8자리 기준으로 같은 피해를 묶고 종료 HP가 높은 라인을 우선합니다. 최초·추가 탐색 개수만큼 서로 다른 피해의 라인을 찾으며, 가능한 종류가 적으면 그만큼만 표시합니다. 각 분기는 고정된 행동을 기준으로 별도로 묶습니다. 수동 편집 행은 비교용으로 유지됩니다. 옵션은 전체 설정 JSON에도 저장됩니다.
- **전체 딜량 분포**: 전체 라인을 대미지 구간별로 묶어 생존(초록)과 사망(회색)으로 표시합니다. 막대에 마우스를 올리거나 ‘구간별 라인 수 보기’를 펼쳐 수치를 확인할 수 있습니다. 치명타를 반영한 각 라인의 기대 딜량 분포이며, 개별 치명타 발생 결과의 분포는 아닙니다.

사망한 라인의 피해는 사망 턴의 플레이어 공격까지 합산합니다. 사망 후 실행하지 못한 뒤쪽 행동 조합도 `6^N` 분모에 포함되므로 같은 사망 경로가 여러 고정 라인에 해당할 수 있습니다. 추천 개수, 같은 대미지 생략, 표의 수동 분기는 전체 통계의 기준을 바꾸지 않습니다. 입력을 바꾸면 추천 표가 먼저 표시되고 전체 통계 계산이 이어집니다.
