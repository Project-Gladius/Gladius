# 시뮬레이터 사용 방법

**[Gladius 통합 시뮬레이터.html](Gladius%20통합%20시뮬레이터.html)**을 Chrome 또는 Edge로 엽니다.

1. **Data 폴더 연결**에서 `Balancing/Data`를 선택하면 디스크의 공통 JSON 3개를 읽습니다. 연결하지 않으면 최신 세이브에서 생성한 내장 복사본으로 시작합니다.
2. **공통 능력치**에서 글라디우스·세라의 공격, HP, 방어 시 피해 비율과 피버·회피·강화를 설정합니다.
3. **보스 공격·패턴**에서 패턴 랜덤 설정 / 패턴 사용자 지정 / 공격 직접 지정 중 선택합니다. 패턴명을 눌러 1~4개의 공격을 묶어 편집할 수 있습니다.
4. **최적 행동 탐색**과 **AI 전투 실험**을 각각 실행합니다. 두 실험의 상태·결과·취소는 독립적입니다.
5. 변경한 값은 능력치 / 패턴 / 강화의 **JSON 저장** 버튼으로 해당 파일에 저장합니다. **JSON 직접 편집**도 지원합니다.

현재 위치 회피 ON은 해당 구역 회피를 허용하고 OFF는 제외합니다. 방어 시 피해 비율 50%는 기존 피해 ÷2와 같으며, 글라디우스·세라를 각각 설정합니다. 실제 공격 피해는 언제나 반올림합니다.

초기값은 `Saves/V1_2026-09-09T06-34-31-643Z.json` 기준입니다. 기존 세이브 파일은 그대로 보존되어 있습니다.

상세 규칙·데이터 규격·빌드 및 테스트 방법은 [통합 시뮬레이터 안내](Simulator/README.md)를 참고하세요.
