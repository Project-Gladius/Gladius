# 상태 JSON 적용 안내

수정한 두 HTML은 schemaVersion 2 보스 JSON의 states와 patterns를 인식합니다.

- `Gladius 통합 시뮬레이터.html`: 상태·패턴 편집, 상태 형식으로 저장, JSON 하나만 불러오기 지원.
- `Gladius 시뮬레이터.html`: JSON 메뉴에서 보스 파일 선택 → 가져오기 미리보기 → 이 설정 적용. 패턴을 한 턴 한 상태로 펼칩니다. 전체 설정 저장 시 원본 상태·패턴 라이브러리도 `bossStateLibrary`에 보존합니다. 이 화면의 턴별 편집은 펼친 전투표를 수정하며, 원본 상태 라이브러리 편집은 통합 시뮬레이터에서 합니다.

## 수정 이유

구형 HTML들은 서로 다른 스키마의 actions, steps, kind 등을 요구했습니다. 새 파일의 states, sequence, totalDamage, vulnerabilityByZone를 읽는 연결을 추가했습니다. resistant는 기존 계산기의 enduring(기본 0.5배)으로 변환하고 물리·마법 모두 같은 취약도를 적용합니다. 총 대미지는 타격 구역별로 적용하며 구역 수로 나누지 않습니다.

Fury는 매 상태 발생 시 후보 중 한 구역만 시드에 따라 무작위로 선택합니다. 예고 텍스트를 보존하며 모션·카메라 필드는 상태 JSON에 추가하지 않습니다.

2·3턴 패턴만으로도 10턴을 끝까지 채울 수 있게, 다음에 1턴이 남는 선택지는 추첨에서 제외합니다. 패턴을 자르거나 임의 상태를 덧붙이지 않습니다. 정확히 채울 방법이 없으면 오류를 표시합니다.

## 저장 형식

보스 저장은 states와 patterns를 유지합니다. 통합 시뮬레이터에서 저장하면 시드, 전투 턴 수, 가중치와 선택 순서를 보존하는 선택적 `simulation` 설정도 추가합니다. kind, bossId, zoneIds는 추가하지 않습니다.

HTML을 더블클릭하면 빌드 시 내장한 데이터로 시작합니다. JSON을 수정한 뒤에는 JSON 불러오기로 최신 파일을 다시 적용하세요. 실제 저장소의 보스 파일 위치는 `Data/bosses.json`입니다.
